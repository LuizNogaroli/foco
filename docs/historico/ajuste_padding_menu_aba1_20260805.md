# Ajuste de Padding do Menu Adicionar Imóvel na Aba 1 - 05/08/2026

## Descrição da Mudança
O `padding-bottom` do contêiner que agrupa os botões de "Adicionar Imóvel/Área" na Aba 1 foi aumentado de `220px` para `350px`. Este ajuste foi necessário para garantir que todos os itens dos menus dropdown (que agora contêm 7 opções cada) sejam totalmente visíveis ao passar o mouse, sem serem cortados pelo layout da página.
